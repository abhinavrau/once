# 05 - Record the findings, delete the prototype

**What to build:** Close the loop. The prototype exists to answer design
questions, not to become production code. Capture what it settled, remove it,
and draft the real implementation tickets from what was learned.

**Blocked by:** 03, 04.

**Status:** ready-for-agent

- [ ] What the prototype settled is written down, as an ADR-0017 amendment or a follow-up doc.
- [ ] What it disproved is recorded too, including any decision ADR-0017 states that the prototype contradicted.
- [ ] The prototype is removed, and no production code depends on it.
- [ ] Implementation tickets for the real flow are drafted from the findings.
